# 청약 블로그 원고 생성기

가상 인물 5명(`profiles/*.yaml`)마다 지원할 수 있는 청약홈 분양·LH 임대 공고를 골라
네이버 블로그 원고를 만들어 메일로 보낸다. 월·수·금 06:00(KST), 인물 한 명당 글 한 편.

- 판정·수집 코드는 청약 알리미 베타(`cheongyak-alert-beta`)에서 복사했다. 베타와 따로 운용한다.
- 지난 원고 뒤로 **새 공고가 없는 인물은 건너뛴다.** 새 공고는 최대 6건(분양·임대 반씩)만
  자세히 쓰고, 나머지는 '계속 접수 중' 목록에 한 줄씩 적는다. 자세히 쓰지 못한 새 공고는 다음 원고에서 자세히 쓴다.
- 인물은 직장이 없어 통근시간을 계산하지 않는다(ODsay 미사용).
- 인물 파일은 실존 인물이 아니므로 저장소에 커밋한다.

## 원고 메일 쓰는 법 (반자동)

1. 메일 위쪽 노란 상자에서 **카테고리·제목·태그·예약 발행 시각**을 확인한다.
2. 빨간 안내 아래 선부터 끝까지 복사해 네이버 스마트에디터에 붙여 넣는다.
3. 그래프가 빠지면 메일의 그래프 이미지를 저장해 넣는다.
4. 카테고리를 고르고 예약 발행 시각을 맞춰 발행한다.

검증 메모가 '없음'이 아니면 붙여 넣기 전에 그 공고를 공고문으로 확인한다.

## 실행

```
python -m src.main --preview preview          # 메일 대신 preview/<별칭>.html (이력 안 남김)
python -m src.main --only p1-youth            # 한 명만 실제 발송
SELFTEST=1 python -m src.main                 # 자체 점검
```

GitHub 시크릿: `ODCLOUD_SERVICE_KEY`, `KAKAO_REST_API_KEY`, `GMAIL_ADDRESS`, `GMAIL_APP_PASSWORD`, `BLOG_TO`(선택).

## 인물 바꾸기

`profiles/<별칭>.yaml` 의 `blog:` 블록이 글에 나가는 소개다(카테고리·라벨·소개·요약·태그·예약 시각).
나머지 항목은 베타 프로필 양식과 같다. 바꾼 뒤 `data/seen/<별칭>.json` 을 지우면 처음부터 다시 쓴다.

## 아직 없는 것

- 분양 판정에 다자녀·노부모 부양·신생아 특별공급이 없다(신혼·생애최초·일반·무순위만). 임대는 다자녀 유형까지 본다.
- 네이버 자동 발행: NAS(DS225+) 구축 후 Docker + Playwright 로 붙일 예정. 실패하면 지금처럼 메일 원고로 돌아온다.
